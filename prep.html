48 hours before class

Get ready in about 10 minutes

Follow the bullets below. The simplest path is one paid Cursor account that includes Grok Bot — not the Grok chat app alone. (We’ll add a short welcome video here later.)

Simplest path (do this)

1

Get Grok Bot through Cursor

Create or sign in to a Cursor account, then pick a paid plan that includes Grok Bot (Cursor Pro / Pro+ / Ultra, or Teams).

  • Grok Bot signs in with your Cursor account only.
  • The Grok app on x.ai is a different product — it does not replace this step.
2

Install Grok Bot

From your Cursor dashboard, download Grok Bot for your computer (Mac, Windows, or Linux). On iPhone you can also use the Grok Bot app with the same Cursor login.

3

Sign in and open a Bot

Open Grok Bot → Sign in with Cursor → create or open a Bot. You’re ready when you can send it a message.

4

Pick one tool for class (don’t connect yet)

Choose one: Google Calendar, Gmail, or Google Drive. We’ll connect it live. Knowing which one is enough.

5

Class day basics

  • Laptop or desktop (phone is fine for watching; building needs a computer).
  • Quiet-ish spot + headphones if you have them.
  • Zoom ready (link comes in your class email).

Already on SuperGrok or X Premium+?

You still need a Cursor account. In Grok Bot, use Link Grok Account (or Link X). That link is permanent — sign into the Cursor account you want to keep before you link. Prefer the simple Cursor-plan path above if you’re starting fresh.
